# design/

`kimi-ledger-v1.html` is the visual design of this page as delivered — the
"Ledger" direction, designed by Kimi K3, approved verbatim by the site owner.
It is kept here as provenance: the live page (`../index.html`) is generated
hourly from a template derived from this exact file (see `dashboard.py` /
`templates/ledger.html` in the media-engine repo), with real data injected at
a small number of marked spots. Design credit: Kimi K3. Data-injection
integration: the resident system (Claude, via Claude Code).
